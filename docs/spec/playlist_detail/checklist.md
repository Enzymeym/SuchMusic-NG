# 检查清单 (Checklist)

- [ ] API 接口请求是否正常，参数是否正确传递（尤其是 `limit` 和 `offset`）？
- [ ] 路由跳转是否携带了正确的歌单 ID？
- [ ] 详情页头部是否正确展示了歌单封面、标题、描述等信息？
- [ ] 详情页头部是否展示了正确的动态数据（如播放量）？
- [ ] 歌曲列表能否正确渲染，歌曲的元数据（标题、歌手、专辑、封面、时长）是否齐全？
- [ ] 歌曲列表是否支持分页或滚动加载更多，直到加载完所有歌曲？
- [ ] “播放全部”按钮是否能正确将当前已加载的歌曲添加到播放列表并开始播放？
- [ ] 单击歌曲列表中的某首歌，是否能正确触发播放（且携带正确的 `source: 'netease'` 与 `sourceSongId`，能够触发 `PlayerBar` 里的在线获取逻辑）？
- [ ] `HomeView`、`PlaylistSquareView`、`ToplistView` 中的歌单卡片点击是否都能正常进入在线歌单详情页？
